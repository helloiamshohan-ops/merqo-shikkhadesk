## ⚠️ Current project status — READ FIRST

This repository is at an **early foundation stage**. It is **not** a finished or
commercially distributable product yet.

- The build environment available to the current engineering session is
  **Debian Linux with no .NET SDK and no Windows**. WPF cannot be compiled or
  run here, and no .NET SDK is reachable from the restricted network. Therefore
  **no executable, installer, or compiled test has been produced in this
  environment.** Nothing in this repository claims otherwise.
- Work completed so far is: repository/environment audit, the full
  documentation set, research, original brand assets (including a genuine
  multi-resolution Windows `.ico`), and the architectural source scaffold.
- See [`docs/PROJECT-STATE.md`](docs/PROJECT-STATE.md) for the authoritative,
  evidence-based status and [`docs/KNOWN-ISSUES.md`](docs/KNOWN-ISSUES.md) for
  the exact external blockers and what is required to clear them.

**Do not treat any module as "done", "tested", or "released" unless the
corresponding evidence is recorded.** This project never fabricates success.
