## Gap summary [ANALYSIS]

**Where the market is crowded:** student records, admissions, batches,
attendance, exams/results, basic fees, SMS, portals. Competing here on features
alone is a losing battle.

**Where ShikkhaDesk can lead (evidenced gaps):**
1. **Offline-first + LAN host/client with local data ownership.** Every major
   competitor is cloud/SaaS. CoachDesk BD is offline-first but is a small beta
   project and not a polished Windows desktop product. This is the primary wedge.
2. **True double-entry accounting** (journal → GL → trial balance → P&L → balance
   sheet → cashbook/bankbook → payables → payroll → statements). Competitors offer
   "income/expense" and a single "balance sheet," not a balanced double-entry
   engine. This is the strongest technical differentiator for a product explicitly
   named "…& Accounts."
3. **Perpetual-use license** (no recurring fee to keep working) vs. the market's
   per-student/monthly SaaS norm. Sabaaq's one-time ৳20,000 tier is the only
   comparable; Zaman IT's ৳50k–150k one-time tiers are pricing precedent.
4. **Signed, institution-bound, offline activation** with device management —
   none of the competitors evidence a comparable licensing system.
5. **Simple-Bengali Windows desktop** for low-computer-literacy operators — the
   market is overwhelmingly web/mobile.

**Where ShikkhaDesk should NOT over-invest in v1:** parent/student portals, SMS,
gateways, biometrics — all are either cost-bearing or cloud-dependent and would
erode the offline/ownership positioning. Keep them optional.
