## What it is
MERQO ShikkhaDesk is an **offline-first Windows desktop** application that runs a
Bangladesh coaching center's full operating cycle — admissions, students, batches,
attendance, exams & results, fee assessment & collection, receipts, advance credit,
income & expenses, cash/bank, **complete double-entry accounting**, payroll,
suppliers & payables, financial statements, reports, backup/restore, user
permissions, and a separate private License Manager — sold as an
**institution-specific perpetual-use license** with the institution's data staying
on its own computers.

## Why it exists (market gap)
The market is dominated by cloud SaaS with recurring fees and vendor-held data;
"accounts" usually means an income/expense list, not a real double-entry system.
ShikkhaDesk's wedge is **offline-first + local data ownership + perpetual license +
true double-entry + simple Bangla**, for low-computer-literacy operators. See
`COMPETITOR-RESEARCH.md`, `COMPETITOR-GAP-MATRIX.md`, `PRODUCT-POSITIONING.md`.

## Who it's for
- **Primary:** small-to-mid single-site coaching centers moving off paper.
- **Secondary:** larger institutions needing real accounting, roles/permissions,
  audit history, and LAN operation across up to five registered computers.

## Scope
- **v1.0 = Tier A (core coaching) + full Tier B (double-entry accounting).**
  See `FEATURE-MATRIX.md`. Tier C (multi-branch, question banks, ID cards/
  certificates, library, inventory, portal) and optional integrations (SMS,
  gateways, biometric) are **staged/omitted by design** and disclosed (DEC-5).
